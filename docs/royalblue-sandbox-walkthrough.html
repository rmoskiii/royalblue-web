Passwords (everyone)

New passwords must be 12+ characters with an uppercase letter, a lowercase letter, a number, and a symbol. Examples that work: RoyalBlueStaff1! · DeskHandover2026#. password123 does not meet the rule.

Every account already in this environment was flagged to change password. You do not get a session on the old password.

  1. On login, enter email + the current password (for the three desk logins below, that is still password123 until you change it).
  2. If the screen stays on login and says to update your password, click Forgot password on that same page. Do not reuse a code that arrived from the login attempt.
  3. Enter the same email → Send code → use the new 6-digit email code → set a password that matches the checklist.
  4. Return to login with the new password. New browsers may ask for a second email code (device trust).

Forgot password does not sign you in; it only replaces the password. After a successful change, password123 will no longer work for that inbox.

Staff onboarding (no KYC)

Desk logins are invite-only. That is so freeze, recommend, and decide are tied to a named person — not a shared inbox. There is no BVN, NIN, selfie, or address on this path. This is not a customer account and does not mint a NUBAN.

Administrator invites

  1. Sign in as product@budpay.com (after the password change above).
  2. Open Team on the desk.
  3. Fill first name, last name, work email, Nigerian phone, role (loan officer, credit manager, or administrator).
  4. Send invite. The email must not already be on any RoyalBlue account (staff or customer). A 6-digit code is mailed to that work inbox.

Invitee finishes

  1. Open /staff-join (also linked as “Join here” on login). Do not use customer Create account.
  2. Enter the invited work email → Email me a code if you need another code.
  3. Enter the 6-digit code and a password that meets the 12-character rule.
  4. You land on the credit desk for that role. New browsers may ask for a device email code.

Unfinished invites cannot log in at /login until this join step is done. Actions on a file show the staff member’s name from the invite, not a generic “admin”.

Change role or remove

On Team, an administrator can change Permissions on an existing row (loan officer / credit manager / administrator). The new role applies on the next request. Remove takes them off the desk and ends their sessions; assigned loan files stay in the queue unassigned. You cannot remove or demote the last administrator, and you cannot remove your own login. The email can be invited again after a remove.

How customer onboarding works

Use a new email that can receive mail. Do not reuse old customer@ / starter@ accounts. If the email is already registered, login opens instead of Home. Customer passwords must meet the same 12-character rule from the start.

  1. Email. We send a 6-digit code.
  2. Verify email. Enter that code (not the PIN you set later).
  3. Password (checklist on screen).
  4. Authenticator only if the API asks for it. You can usually skip this for now.
  5. Personal or business. Business is a wallet (money in / send), not POS or cashiers.
  6. Name and phone.
  7. BVN and/or NIN. Both fields are on the same screen. Prefer both; at least one is required. NIN must be unique across accounts. There is no skip and no phone-only “starter” account.
  8. Confirm identity (“Is this you?”). Shows the name, date of birth, and the residential address on the BVN/NIN record.
  9. Live selfie. Optional now — same step later under Account limits. Allow camera; the light should go off after you take the photo, continue, or skip. Selfie is not required on every transfer.
  10. Residential address. Prefills from the identity record. You can confirm it, upload a utility bill, or skip. Tier 3 only unlocks if the bill address matches NIMC; anything else goes to staff.
  11. Business details if you chose business.
  12. 6-digit transaction PIN (create, then confirm). This is for sends and bills, not the email code.

After PIN, you land on Home. A dedicated NUBAN (virtual account) is minted when BVN or NIN is on file. Inbound transfers credit that VA. Outbound NIP debit the merchant wallet against the customer’s ledger. Intra-RoyalBlue stays on our books.

Worth walking

  1. Change a desk password via Forgot password, then sign in and land on /admin.
  2. As administrator, invite a colleague from Team. They finish at /staff-join with no BVN. Confirm their name shows on a recommend / freeze / decide.
  3. Sign up a customer with a real BVN, a real NIN, and both — confirm the address on the identity screen, then check Home for a NUBAN.
  4. Skip selfie and address, then complete them from Account limits. Try a send (needs the PIN you set).
  5. Business signup: wallet dashboard and money in, not a till.
  6. Same loan file as officer vs manager vs admin — who can claim, recommend, freeze, decide.
